# R_teach_in

The code and materials for "Quantitative Methods for Typologists Using R" teach-in during ALT2022 (14th Conference of the Association for Linguistic Typology) taught by Sandra Auderset, Olena Shcherbakova, and Adam Tallman.

Session on *Tidyverse and Data Wrangling*:
`wrangling_Glottolog.Rmd` contains data wrangling of Glottolog and a task
`wrangling_Glottolog_solution.Rmd` contains the solution to the task
`wrangling_Slides_examples.Rmd` contains the code used for preparing visuals in the presentation part devoted to data wrangling
`wrangling_WALS.Rmd` contains data wrangling of WALS

The selection of R cheatsheets from different packages: https://posit.co/resources/cheatsheets/
